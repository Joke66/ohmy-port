# 接口文档 — OhmyPort

> 记录 Core↔App 的接口契约、配置 JSON 结构、日志文件格式。改动任何一侧前先核对本文档，避免破坏老配置兼容性。

## 1. Core ↔ App 接口契约

### 1.1 App 调用 Core

- `AppPaths`：取 `ConfigPath`、`DefaultLogDir`、`DefaultBgDir`。
- `ConfigService`：`Load()` 启动读配置，`Save()` 关闭/变更时写回。
- `AppConfig` / `SessionConfig`：反序列化结果 + `Normalize()` 校验 + 构造回写。
- `CommandItem` / `CommandPages.Load`：命令页/命令解析与校验。
- `SerialSettings` / `SerialMonitor`：`Connect` / `Disconnect` / `Send` / `SetDtr` / `SetRts` / `Received` 事件 / `IsConnected` / `RxBytes` / `LastError`。
- `FrameParser` / `SetFrameParser`：当前未接线（预留）。
- `SendCodec`：`ParseHex` / `ParseEscaped` / `GetEncoding`。
- `LogFilter` / `FilterModes`：`ParseKeywords` / `Visible` / `Matched`。
- `TextUtil`：`FormatBytes`（状态栏字节计数）、`ExtractNumbers` / `FormatValue`（绘图预留）。
- `LogManager`：`Open` / `Write` / `Flush` / `Close` / `CleanOldLogs`。
- `LogRetention` / `Themes` / `SerialDefaults` / `UiDefaults`：常量表与下拉选项数据源。
- `PlotRule`：当前未接线（预留，M7 绘图）。

### 1.2 App 内部关键约定

- `Option(Label, Value)`：下拉项通用包装（`DisplayMemberPath=Label`、`SelectedValuePath=Value`）。
- `LogDirection`：Rx / Tx / Sys 三方向。
- `LogRecord(Time, Direction, Data, Text, ChecksumOk)`：一条待显示/已缓存日志。
- `SessionView` 暴露给 `MainWindow` 的接口：
  - 视图开关：`WrapEnabled` / `HexView` / `FixedView` / `FilterVisible` / `ParamsVisible` / `SendVisible`。
  - 字体：`SetFontSize` / `ZoomIn` / `ZoomOut` / `ResetZoom` / `SetLogFontFamily` / `FontSizeValue`。
  - 过滤持久化：`ApplyRememberedFilter` / `FilterKeywordsText` / `FilterModeKey` / `FilterCaseSensitive` / `FilterEnabledState`。
  - 发送/记录：`SendCommandContent` / `AddSystemText` / `SaveLog` / `StartRecord` / `StopRecord` / `ToggleRecord`。
  - 主题/生命周期：`ApplyThemeColors` / `Shutdown` / `LogControl`。
  - 注入属性：`LogDirectory` / `ShardMb` / `AutoRecord` / `Index` / `RememberedPort` / `BaudText` / `SelectedPort`。
  - 事件：`TitleChanged` / `StatusChanged`。

## 2. 配置 JSON 结构（`serial_tool_config.json`）

字段名沿用旧版 snake_case，`System.Text.Json` 按 `SnakeCaseLower` 命名策略映射到 `AppConfig` 属性。老配置可直接读取。

顶层字段（`AppConfig`）：

- `theme`：`auto` / `black` / `day` / `eye`。
- `pages`：命令页名数组，默认 `["第1页"]`。
- `commands`：命令数组，元素含 `name` / `content` / `cycle` / `page`。
- `auto_record`：连接后自动记录日志。
- `shard_mb`：日志分片大小（MB，最小 1）。
- `log_retention`：`week` / `month` / `half_year` / `year` / `unlimited`。
- `last_update_check`：上次更新检查时间戳。
- `font_family`：日志字体。
- `wrap_enabled`：自动换行。
- `close_behavior`：`exit` / `tray`。
- `close_confirm`：关闭时询问。
- `log_dir`：自定义日志目录（null 用默认）。
- 背景皮肤：`bg_dir` / `bg_image` / `bg_blur`(0~50) / `bg_veil`(0~100) / `bg_enabled`。
- `sessions`：会话数组，元素含 `port` / `baud` / `custom_bauds` / `filter_keywords` / `filter_mode` / `filter_case` / `filter_enabled` / `font_size`。

兼容性说明：

- `port` / `baud` 用 `FlexibleStringConverter`，旧版里数字型 baud 也能读。
- 未知字段、注释、尾逗号均被容忍（`ReadCommentHandling.Skip`、`AllowTrailingCommas`）。
- 非法值由 `Normalize()` 回退默认，不会导致启动失败。

## 3. 日志文件格式

- 路径：`<logDir>/<stem>_yyyyMMdd_HHmmss.txt`，`stem` 为端口名 sanitize 后（如 `COM3`）。
- 编码：UTF-8 无 BOM，行尾 `\r\n`。
- 行格式（固定文本，不受「HEX 显示」开关影响）：
  - 接收：`[HH:mm:ss.fff] <正文>`
  - 发送：`[HH:mm:ss.fff] SEND >>>>>>>>>> <正文>`
  - 系统：`[HH:mm:ss.fff] ◆ <文本>`

## 4. 显示行格式约定

- 与落盘格式一致，仅正文在 HEX 显示模式下被 `ToHex` 转成 `01 03 0A` 形式。
- `LogColorizer` 依赖 `[时间戳] ` 与方向标记前缀做着色，改动格式需同步改 `Controls/LogView.cs` 的着色逻辑。

## 5. 帧协议配置约定（预留）

- 校验类型字符串：`none` / `sum8` / `xor8` / `crc16_modbus`（`FrameParser.ParseChecksum`）。
- 帧结构：`[帧头][长度字段?][数据][校验][帧尾]`，长度字段大小 / 字节序 / 长度基准可配。
