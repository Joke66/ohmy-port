# 研发需求文档（TRS）— OhmyPort

> 本文档从 wpf 分支现有代码倒推而来，作为功能需求的单一真相源。相对原版（Python 版）的目标是完整、一致；后续迭代遵循「先改文档、再改代码」。

## 1. 范围与目标

- 在 Windows 上提供一款串口调试助手，替代 Python + PySide6 原版。
- 使用 C# / WPF + .NET 10 自包含发布，目标更小体积、更快冷启动，功能体验与原版对齐。
- 不做脚本引擎、插件体系等超出「串口调试常用」的范围。

## 2. 功能需求（FR）

### FR-串口连接与收发

- FR-1 多串口会话：支持多个串口标签页，每个会话独立连接参数与日志区。
- FR-2 端口枚举：列出可用串口，显示 WMI 友好名（如 `COM3 USB-SERIAL CH340`），支持刷新。
- FR-3 连接参数：波特率（可自定义输入）、数据位（5/6/7/8）、停止位（1/1.5/2）、校验位（无/奇/偶/标记/空格）、流控（无/RTS-CTS/XON-XOFF）、DTR/RTS 开关。
- FR-4 收发：文本与 HEX 两种发送/显示；发送支持 `\r \n \t \0 \xNN \\` 转义；发送可追加换行（无/`\r`/`\n`/`\r\n`）。
- FR-5 编码：UTF-8 / GBK / ASCII 可切换。
- FR-6 连接状态指示：标签页绿点 + 状态栏端口/波特率/编码/连接状态。
- FR-7 热插拔检测：连接中端口被拔出自动断开并提示；端口集合变化自动刷新列表。
- FR-8 统计：RX/TX 字节计数（人类可读格式）。

### FR-日志显示

- FR-9 时间戳显示（`HH:mm:ss.fff`），发送/系统消息方向着色。
- FR-10 暂停/继续：暂停冻结 rx/tx 显示，后台仍缓冲，恢复全量重建。
- FR-11 清空显示与缓冲区。
- FR-12 固定显示：日志持续追加但保持当前滚动位置。
- FR-13 自动换行开关。
- FR-14 字号缩放（Ctrl+= / Ctrl+- / Ctrl+0、Ctrl+滚轮）。
- FR-15 复制选中 / 复制全部。
- FR-16 搜索（Ctrl+F / F3 / Shift+F3）。
- FR-17 行数上限裁剪（默认 50000 行）。

### FR-关键词过滤

- FR-18 四种模式：显示全部并高亮 / 仅显示命中行 / 排除命中行 / 上下分栏显示命中行。
- FR-19 多关键词（逗号/空格分隔）+ 区分大小写开关。
- FR-20 命中关键词高亮。

### FR-发送辅助

- FR-21 命令页：多页、每页最多 8 个命令，命令可添加/编辑/删除。
- FR-22 命令一键发送到当前会话。
- FR-23 定时循环发送：可启用/停用、设间隔（10ms~1h）、勾选参与循环的命令、轮流发送；每条命令可设「发送后延时」，发完这条等该延时再发下一条（0 用全局间隔）。

### FR-日志记录

- FR-24 连接后自动记录（可关）。
- FR-25 手动开始/停止记录。
- FR-26 日志分片（按 MB 大小，可配）。
- FR-27 日志保留策略（一周/一月/半年/一年/无限制），到期自动清理。
- FR-28 自定义日志保存目录，打开日志目录。
- FR-29 保存当前日志到指定文件。

### FR-个性化

- FR-30 四套主题（跟随系统/深色/白天/护眼），跟随系统深浅自动切换。
- FR-31 背景皮肤：目录/图片选择、模糊强度、背景遮罩浓度、启用开关。
- FR-32 日志字体选择（等宽字体）。
- FR-33 关闭时最小化到托盘 / 直接退出，可设「不再提示」。

### FR-配置

- FR-34 配置持久化（`serial_tool_config.json`），与旧版字段兼容。
- FR-35 配置导入/导出（JSON）。
- FR-36 会话状态恢复（端口/波特率/字号/过滤）。

### FR-协议调试

- FR-37 自定义帧协议解析：按帧头/长度字段/帧尾/校验（SUM8/XOR8/CRC16-Modbus）从字节流切帧；帧校验失败显示系统提示；协议设置按会话持久化。
- FR-38 发送自动算校验：发送时对最终字节追加校验字节（SUM8/XOR8/CRC16-Modbus，CRC 低字节在前），追加在换行之前；按会话持久化。
- FR-40 校验计算器：输入 HEX 字节，实时显示 SUM8/XOR8/CRC16-Modbus 结果并可复制。
- FR-41 协议字段解析：按字段定义（名称/偏移/类型/字节序/系数/偏移量）把最新一帧解成「名称 | 类型 | 值 | 原始 HEX」表格；支持 uint8/int8/uint16/int16/uint32/int32/float32/float64/hex/ascii；偏移相对数据区（帧头+长度字段之后）；越界字段标红显示「—」；字段定义按会话持久化。
- FR-39 实时曲线：配置「名称 + 提取规则（正则捕获组或关键词）」后，从接收日志行实时提取数值绘制折线；自动缩放 Y 轴、缺失值断线、图例显示最新值；窗口点数可配（200/600/2000/10000）；支持清空与暂停刷新；规则按会话持久化。
- FR-42 文件发送（下发）：选文件后按格式分块逐块发送，支持三种格式（HEX 文本 / 文本行 / 二进制 raw）、分包大小、分包间隔、进度显示与取消。

### FR-界面体验（A/B/C 优化）

- FR-43 全局发送快捷键：Ctrl+Enter 发送当前会话输入框内容；连接成功后自动聚焦发送框。
- FR-44 发送历史：上下方向键回填历史记录；右键可清空发送历史。
- FR-45 会话标签：右键菜单（重命名 / 复制会话 / 关闭）；双击标题重命名；自定义标题按会话持久化。
- FR-46 状态栏：显示实时收发速率（B/s）+ 当前会话名。
- FR-47 HEX 显示：每 16 字节一行，右侧 ASCII 对照（不可打印字符显示为 `.`）。
- FR-48 正则过滤：关键词可作为正则表达式匹配（与四模式组合，非法正则忽略）。
- FR-49 时间戳显示档位：完整（HH:mm:ss.fff）/ 仅秒（HH:mm:ss）/ 不显示，按会话持久化。
- FR-50 应答高亮：发送后收到的第一条接收行用应答色标记。
- FR-51 协议面板详情可折叠，减少对日志区的占用。
- FR-52 窗口位置 / 大小退出时记忆、启动时恢复（越界回退居中）。
- FR-53 主题强调色可自定义（覆盖默认 Brush.Accent 系列，按亮度决定前景色）。

### FR-视觉打磨（2.0 美观优化）

- FR-54 控件反馈：TextBox/ComboBox/Button 悬停与键盘焦点时用强调色描边（ComboBox 打开/悬停已高亮）。
- FR-55 状态栏连接色点：当前会话连接状态以绿点（连接）/灰点（未连接）显示在状态栏左侧。
- FR-56 空态提示：主日志区无数据时居中显示「等待数据…」弱化提示；字段面板与曲线窗口同样有占位提示。
- FR-57 面板淡入：视图面板显示时 120ms 淡入过渡（隐藏即时收起，不影响日志高频渲染路径）。
- FR-58 日志控件构造即应用主题底/前景/光标色，避免新建会话瞬间白底。

### FR-帮助与开源合规

- FR-59 关于对话框：应用标识 + 版本 + 定位说明 + 开源（GPL-2.0）声明 + 无担保声明 + 作者/技术栈 + 可点击的源码仓库链接 + 免责声明。
- FR-60 开源许可展示：帮助菜单「开源许可」读取随程序嵌入的 LICENSE 全文并只读展示（满足 GPL「告知如何查看许可证」要求，离线可用）。
- FR-61 项目主页：帮助菜单「项目主页」用默认浏览器打开仓库地址。
- FR-62 检查更新：请求 Gitee API，比较最新 tag 与当前版本（`TextUtil.ParseVersion`/`CompareVersions`），有新版本提示并打开发布页，失败/无更新给明确反馈。
- FR-63 滚动条主题：全局 ScrollBar 换细圆角滑块，颜色跟随主题画刷（悬停/拖动用 Hover/Accent），避免深色主题下系统默认滚动条突兀。

## 3. 非功能需求（NFR）

- NFR-1 性能：日志区 5 万行上限下追加/裁剪/实时追加流畅（实测批量追加 133ms、实时 40 行/批平均 0.04ms）。
- NFR-2 稳定性：串口回调异常、磁盘满、WMI 不可用等异常不崩溃；未处理异常写 `error.log`。
- NFR-3 体积与启动：单文件自包含约 67 MB，冷启约 1.6s。
- NFR-4 兼容性：Windows 10 1607+ / 11，目标机器无需预装 .NET。
- NFR-5 可测试性：Core 层无 UI 依赖，全部逻辑可单测。
